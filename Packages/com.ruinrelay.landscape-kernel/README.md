# Landscape Kernel 0.3 preview
Standalone Unity Editor package. Install this folder with Unity Package Manager or use the Git URL in the repository README. No runtime component or custom server is required.

Tools → Landscape Kernel → Live Preview opens the preview window. See Documentation~/REQUEST.md for the JSON interface. The optional Codex skill and PowerShell adapter are in the repository skills/ directory.

Technical execution and visible effect are not art or traversal approval. Corridor/material changes have backups and rollback receipts. Ridge is preview-only through the UI/Bridge in this version.
